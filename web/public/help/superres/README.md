# 图像超分 · 使用说明配图

把截图**按下面的名字**放进本目录即可，页面会自己认出来（图不在时显示占位并写明该截什么）。

## 命名规范

```
两位序号 + 小写扩展名
```

- 文件放这里：`web/public/help/superres/`
- 名字就是 `01.jpg`、`02.jpg` …… 一直到 `07.jpg`
- 扩展名 `png` / `jpg` / `jpeg` / `webp` 都认，**按这个顺序优先**（同一序号若 png 与 jpg 并存，用的是 png）。
- **截图建议用 jpg**：实拍数据是 12 张 PNG→JPEG（质量 90）后 19.83 MB → 4.38 MB，约 4.5 倍。
  例外：**大片纯色的界面图** PNG 反而更小。
- 序号 = **在说明页里出现的顺序**，下面的表就是对照表。
- 页面地址（本地开发）：<http://localhost:5173/help/superres>

> 页面里的占位框会直接写出「应该叫什么名字」，拿不准时打开页面看占位即可 —— 以页面为准。

## 序号对照表

| 文件 | 图注 | 该截什么 |
|---|---|---|
| `01.jpg` | 原图区（拖入或点击选择） | 刚进 /superres 的左侧「原图」卡：虚线拖放区 +「拖入截图，或点击选择」+「支持 PNG / JPG / WebP」 |
| `02.jpg` | 两条线：超分 / 纹理保全 | 「超分设置」卡最上方两个并排模式按钮，当前选中态可见 |
| `03.jpg` | 超分线：倍率与降噪档位 | 选「超分」后的两排按钮：上排 2x/3x/4x（带「四档降噪 / 三档降噪」副标），下排是当前倍率的降噪档 |
| `04.jpg` | 超分线的两个开关 | 「抗锯齿预处理」与「超分后压缩回原分辨率」两个勾选项 + 各自右侧说明文字 |
| `05.jpg` | 纹理保全线 | 切到「纹理保全」后的设置区：只剩一个开关 + 下面那行 SuperScale→AnimeSharpV4 提示 |
| `06.jpg` | 开始按钮与处理中进度 | 处理进行中：主按钮「处理中…」+ 真实进度条与阶段文字 + 「取消」 |
| `07.jpg` | 结果对比小窗与「下载 PNG」 | 处理完成后的「结果」卡：左半原图 / 右半结果、中间带圆形把手的对比小窗（左上角「原图」角标、右上角「结果」角标）+ 「下载 PNG」；主按钮此时为「重新超分 → Nx」或「重新处理」 |

## 注意

- **不需要全拍**。缺哪张就少哪张，页面显示占位，不影响其余内容。
- 建议**浅色主题**截图（默认主题），宽度 1200–1600px 左右即可，页面会等比缩放。
- 截完直接刷新说明页就能看到，不需要重启 dev server。
- 图片总量会进版本库，压成 jpg 能省一个量级（见上）。
