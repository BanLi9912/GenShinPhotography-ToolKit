# 参考图库 · 使用说明配图

把截图**按下面的名字**放进本目录即可，页面会自己认出来（图不在时显示占位并写明该截什么）。

## 命名规范

```
两位序号 + 小写扩展名
```

- 文件放这里：`web/public/help/library/`
- 名字就是 `01.jpg`、`02.jpg` …… 一直到 `13.jpg`
- 扩展名 `png` / `jpg` / `jpeg` / `webp` 都认，**按这个顺序优先**（同一序号若 png 与 jpg 并存，用的是 png）。
- **截图建议用 jpg**：2026-09-12 把本目录 12 张 PNG 转成 JPEG（质量 90）后，总体积 **19.83 MB → 4.38 MB**（约 4.5 倍）。原图备份在 `.tools/help-originals/`（已 gitignore，不入库）。
  - 例外经验：**大片纯色的界面截图**（如空状态）PNG 反而更小——`01` 转 jpg 后从 0.074 MB 变成 0.092 MB。这类图留着 png 也无妨。
- 序号 = **在说明页里出现的顺序**，下面的表就是对照表。
- 页面地址（本地开发）：<http://localhost:5173/help/library>

> 页面里的占位框会直接写出「应该叫什么名字」，所以拿不准时打开页面看占位即可 —— 以页面为准。

## 注意

- **不需要全拍**。缺哪张就少哪张，页面显示占位，不影响其余内容；可以只补你最在意的那几张。
- 建议**浅色主题**截图（默认主题），宽度 1200–1600px 左右即可，页面会等比缩放。
- 截完直接刷新说明页就能看到，不需要重启 dev server。
- 如果以后想把图序号重排，记得同时改 `web/src/app/help/guides/library.tsx` 里 `FIGURES` 的键
  （那是唯一的序号来源），否则图注会错位。
