# M3 参考图库（library）

绑定本地文件夹的参考图管理器：索引随文件夹走（`.ystk/meta.json` + `index.json`），支持关键字/tag/颜色搜索；识图可选云端 API（自带 key 才启用）。

- 需求与全局决策以《2026-08-07-M3落地细节规划.md》为准（开发文档 §2.3/§4.2 图库部分已被取代）；任务拆分 M3.1–M3.6 见该规划 §3
- 索引为 JSON 单文件（`.ystk/meta.json` + `.ystk/index.json`），写入策略：内存驻留 → dirty 后 1000ms 防抖整文件原子写，每 100 条变更兜底落盘，切换/卸载强制 flush
- 内存模型：缩略图/索引文件均持久化在磁盘；运行内存 = 索引 Map（全量，策略 1）+ 已渲染条目的 objectURL（瀑布流增量追加，M3.3 虚拟滚动做视口外卸载）；分析队列逐张流式并显式 `bitmap.close()`
- 像素数据只允许经 `core/imaging` 处理（M3.2 上移后）；本卡不涉及分析
- 模块约定（§3.3）：对外只暴露 `api.ts`；模块状态在 `store.ts`；组件在 `components/`
- 文件结构：`api.ts` / `store.ts` / `index/`（binding 绑定注册、indexFile 索引读写、scan 扫描比对）/ `pipeline/`（basicAnalysis 单图分析、thumbs 缩略图、queue 分析队列）/ `search/`（similar 相似图、rank 打分引擎 + synonyms 同义词典 + suggest 补全、vector/ 向量引擎 doc+ollama+store）/ `vision/`（云端识图）/ `components/`（LibraryPage / OverviewGrid 虚拟网格 / DetailView 详情页 / FolderDrawer 文件夹树左侧浮层 / GlobalSettingsPanel 全局识图设置 / LibraryRegistryPanel 图库注册表 / revealInFolder 在文件夹中打开的数据层）
- **设置入口（任务 2026-09-08）**：全局（跨图库）识图设置在应用壳顶栏「设置中心」的 M3 分区（经 `api.ts` 导出 `LibraryGlobalSettingsPanel` 装配）；模块内工具栏齿轮（识图设置）为「当前图库」设置（压缩档位 / 预设 / 字段配置 / 词表 / 自定义字段）。识图启动/中止统一走识图小窗。
